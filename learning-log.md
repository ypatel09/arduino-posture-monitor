# Learning Log
Here in the Learning Log, you will find the lessons I completed necessary for 
the Posture Project, along with the progress of the project itself.


## Lesson 2 — Blink

### Goal
- Learn how to upload the Arduino UNO R3 and get everything started.
  
### What I did
- Set up the Arduino UNO R3.
- Uploaded the Blink example.
- Changed delay(1000) to delay(500) and observed that the LED blinked twice as quickly.

### What I learned
- setup() runs once when the Arduino resets.
- loop() repeats continuously.
- delay() controls how long the program waits.

 ## Lesson 3 — LED

### Goal
- Learn how to use LED and resistor with a breadboard.

### What I did
- Built the LED circuit on the breadboard.
- Tested with 3 different resistor values 

### What I learned
- The LED has a positive and negative side (the longer leg being the positive)
- The higher the resistance in the resistor, the lower the current flowing (results in a dimmer LED).
