# Lessons
Here in the Lessons folder, you will find the lessons I completed necessary for the Posture Project, before starting the project itself.

## Lesson 2 — Blink
**What it does:** Makes the Arduino's built-in LED blink on and off.
**What I learned:** I learned how `setup()` runs once and `loop()` repeats continuously. I also learned how `digitalWrite()` and `delay()` control the LED.
**Problem I hit:** No problems occurred

## Lesson 3 — LED
**What it does:** Uses an external LED and different resistors to demonstrate LED brightness.
**What I learned:** I learned that LEDs have positive and negative legs and need a resistor to limit current. I also learned how to connect components using a breadboard.
**Problem I hit:** No problems occurred

## Lesson 4 — RGB LED
**What it does:** Controls a red, green, and blue LED together to produce different colours.
**What I learned:** I learned that an RGB LED contains three separate colour channels. I also learned how PWM and `analogWrite()` control their brightness.
**Problem I hit:** The colors didn't appear how I imagined them to be. I would either be only blue blinking or only green blinking. Turns out I wired the wrong legs.

## Lesson 5 — Digital Inputs
**What it does:** Uses two push buttons to turn an LED on and off.
**What I learned:** I learned how the Arduino reads button presses using `digitalRead()`. I also learned about `INPUT_PULLUP`, where an unpressed button reads HIGH and a pressed button reads LOW.
**Problem I hit:** Example: No problems occurred

## Lesson 6 — Active Buzzer
**What it does:** Makes an active buzzer produce sound when connected to the Arduino.
**What I learned:** I learned that an active buzzer has a built-in oscillator, so it can make sound with a simple electrical signal. This makes it useful for basic alerts.
**Problem I hit:** Example: No problems occurred

## Lesson 10 — Ultrasonic Sensor
**What it does:** Uses an HC-SR04 ultrasonic sensor to measure the distance between the sensor and an object.
**What I learned:** I learned that the sensor sends out ultrasonic waves and measures how long their echoes take to return. I also learned how to use a library and Serial Monitor to display distance readings.
**Problem I hit:** Example: Had issues finding the `< HC-SR04> library` The distance readings also showed inaccurated values when I moved an object in front of the sensor, due to it being positioned incorrectly.

## Lesson 14 — LCD Display
**What it does:** Displays text and changing numbers on a 16-column, 2-row LCD screen.
**What I learned:** I learned how to use the LiquidCrystal library to display information. I also learned how to set the cursor position and print text on different rows.
**Problem I hit:** Example: No problems occurred
